# C++ 底层例题代码集 · 目录

17 个例题，每个文件从新的一页开始；讲解见 `01/02/03-第X阶段-例题讲解.md`。
对照用法：先看讲解里的"真实输出"，再翻到这里的代码页，边读边在纸上标出关键行。
