sizeof(A)=16 sizeof(B)=16 sizeof(C)=32
→ C = A 子对象(vptr+int, 16) + B 子对象(vptr+int, 16) + int c + 填充

同一个对象，三个指针指向不同的位置：
  pc = 0x16d736468（对象首地址）
  pa = 0x16d736468（A 子对象，偏移 0）
  pb = 0x16d736478（B 子对象，偏移 16）

两个子对象各有一张虚表：
  A 子对象的 vptr = 0x1026cc030
  B 子对象的 vptr = 0x1026cc060

通过不同指针调用，都是虚调用，各自查各自的表：
C::fa()（重写 A 的）
C::fb()（重写 B 的）

-- 指针调整是编译器做的，不是免费的 --
  static_cast<B*>(pc)      = 0x16d736478（正确，从对象首地址偏移到 B 子对象）
  reinterpret_cast<B*>(pa) = 0x16d736468（错，等于把 A 子对象当 B 用 → UB）
  dynamic_cast<B*>(pa)     = 0x16d736478（正确，代价是运行时检查）

-- 用基类指针 delete：虚析构保证完整析构 --
  delete 前先看 pb 偏移：B* p = 0x102dd5b30
