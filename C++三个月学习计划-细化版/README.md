# C++ 三个月底层通透学习计划 · 细化版 + 例题演示材料

这套材料是在你原来那份《C++三个月底层通透学习计划》基础上做的两件事：

1. **细化**：把 12 周落到「每天 1 小时做什么、看什么、怎么算过关」，并明确每一条最终都能回到你的 WebView 桌面项目上。
2. **例题化**：16 个**可直接编译运行**的例题，每个都配真实输出、逐行讲解、动手改法和验收问题。代码在 `code/`，讲解在三个阶段的文档里。

## 怎么用

```bash
cd code
bash run_all.sh          # 编译并运行全部例题，输出存到 outputs/*.txt
cmake -S . -B build && cmake --build build -j   # 或者用 CMake 逐个构建

# 重新生成打印稿：
python3 memory-maps/draw.py memory-maps         # 内存结构图（p1_01）
python3 memory-maps/draw_p1_02.py               # 内存结构图（p1_02）
python3 memory-maps/draw_p1_03.py               # 内存结构图（p1_03）
python3 print-out-examples/build_handout.py     # 代码集 HTML + PDF + 预览图（需沙箱外权限）
```

学习节奏建议（每周 7 天）：**D1–D2 概念实验 → D3–D4 底层验证 → D5 对照 Rust → D6 综合小题 → D7 复盘 + 出打印稿**。
每个例题的文档末尾都有「验收问题」，答不上来就别进下一题——这套设计的核心是**能预测、能复现、能口述**，不是看过。

## 这套例题的取材原则

- **每一题都有一条"看不见但能打印出来"的事实**：sizeof、偏移、vptr 地址、容量跳变、引用计数、ASan 报告。不靠术语，靠证据。
- **每一题都对应一个真实踩过的坑**：对齐填充、迭代器失效、异常路径泄漏、循环引用、多继承指针偏移、越界/野指针/重复释放。
- **每一位结论都能回到 WebView 项目**：宿主 C++ 与 Web 前端之间的边界，本质上就是「谁拥有这块内存、活到什么时候、接口在哪张虚表上」。

## 与 WebView 项目的衔接主线（贯穿 12 周）

| 周 | 学到的东西 | 回到项目里做什么 |
| --- | --- | --- |
| 1 | 对象布局/对齐/栈堆 | 搞清楚宿主层结构体的布局，评估跨语言传结构体的成本 |
| 2 | vptr/虚表/多态 | 用抽象基类定义「平台能力接口」（文件、剪贴板、窗口） |
| 3 | string 的 SSO/扩容 | 约定宿主↔前端字符串的所有权与编码边界 |
| 4 | vector 连续内存 | 批量数据（列表/图片帧）零拷贝传递与预留容量 |
| 5 | RAII | 把窗口、句柄、回调注册都包成 RAII 守卫 |
| 6 | 智能指针 | 宿主对象生命周期与前端引用解耦，杜绝悬空回调 |
| 7 | 多继承布局 | 多个能力接口组合时的指针调整与 `static_cast`/`dynamic_cast` |
| 8 | 虚继承 | 共享上下文（配置/日志）只保留一份 |
| 9 | 内存排坑 | 给宿主进程常开 ASan，把崩溃现场变成可复现的最小例子 |
| 10 | 排坑方法 | 用地址/字节对比定位跨边界的内存问题 |
| 11 | 综合项目 | 多态成绩管理 → 换成本项目的领域对象，结构完全一致 |
| 12 | 收口 | 端到端跑通：宿主 C++ + Web 前端，零泄漏、零悬空 |
